# 特种作业操作证识别结果导出需求

## FR-06 将数据库记录导出为 XLSX 表格

**需求状态**　已完成、已验收。

在项目目录执行 `uv run main.py -export`，将已有数据库中的文件处理记录导出为一个 `.xlsx` 工作簿。导出仅读取数据库，无需提供 `--input` 或重新识别源文件。

### 数据库与输出文件

默认读取 `data/ocr.db`。使用 `uv run main.py -export 需显式传入 `--db` 读取指定的数据库。

建议默认将表格保存在所选数据库的同一目录，沿用数据库主文件名，例如将 `data/ocr_fast.db` 导出为 `data/ocr_fast.xlsx`。导出成功后显示实际输出路径和数据行数。

### 工作表列顺序

第一行从左到右使用下表“中文表头”列中的文字，共 13 列。每条 `files` 记录占一行，按入库顺序排列。识别字段均按该记录的 `file_id` 从 `extracted_fields` 取值。

| 列序 | 中文表头 | 取值规则 |
|---|---|---|
| 1 | 编号 | 本次导出的数据行序号，首条为 1，之后逐行加 1 |
| 2 | 姓名 | 识别字段“姓名” |
| 3 | 性别 | 识别字段“性别” |
| 4 | 证号 | `certificate_files.cert_no`，无证件关联时取本文件的识别字段“证号” |
| 5 | 作业类型 | `certificate_files.work_category`，无证件关联时取本文件的识别字段“作业类别” |
| 6 | 操作项目 | 识别字段“操作项目” |
| 7 | 初领日期 | 识别字段“初领日期” |
| 8 | 有效期开始日期 | 识别字段“有效期开始日期” |
| 9 | 有效期截止日期 | 识别字段“有效期截止日期” |
| 10 | 签发机关 | 识别字段“签发机关” |
| 11 | 文件路径 | `files.file_path` |
| 12 | 文件名 | `files.file_name` |
| 13 | 错误原因 | `files.error_message` |

证号按文本原样写入，保留前导零、字母和全部数字。三个日期分别取各自已保存的值，显示格式为 `YYYY-MM-DD`。数据库中的空值和历史记录缺少的字段在表格中留空。

### 验收条件

| 场景 | 预期结果 |
|---|---|
| 库中按顺序保存了一条成功、一条失败和一条不支持格式的记录 | 工作簿可正常打开，表头与上表逐列一致。表头下恰有三行，编号依次为 1、2、3。后两行保留各自的文件路径、文件名和库中记录的错误原因。 |
| 两份文件关联同一证件 | 两份文件各占一行，各行展示本文件的识别值和来源路径。 |
| 某条记录只识别到作业类别，历史记录缺少有效期开始日期 | 作业类别显示在“作业类型”列，对应记录缺失的证号或有效期开始日期留空。 |
| 某条证号以零开头，或为超过 15 位的纯数字 | 在表格中打开并核对，证号与数据库文本逐字符一致。 |
| 数据库表结构完整，文件记录为零条 | 生成只有 13 列中文表头的工作表，提示导出 0 条。 |
| 所选数据库不存在、无法读取或工作簿写入失败 | 命令显示具体原因，以非零状态退出。 |
